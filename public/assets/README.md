# Assets de marca — ChilenosProyección

## Logo definitivo

| Archivo | Uso |
|---------|-----|
| `brand/logo-cp.png` | Logo monograma sobre naranja `#EB7C2B` (exportado desde el arte original rojo) |
| `brand/logo-cp-mono.png` | Solo monograma blanco (fondo transparente) |
| `logo-placeholder.svg` | SVG fallback CP en naranja |

### Cómo reemplazar el logo

1. Exportá el logo final en PNG (cuadrado, min. 512×512) y SVG.  
2. Reemplazá `brand/logo-cp.png` y/o `logo-placeholder.svg`.  
3. El header usa:  
   `public/assets/brand/logo-cp.png` con fallback al SVG.  
4. Favicon: añadí `favicon.ico` y `apple-touch-icon.png` en `public/` y enlazá en `includes/header.php`.

## Colores de marca

- Naranjo: `#EB7C2B`  
- Naranjo deep: `#c45f15`  
- Negro / blanco para tipografía y fondos
